# La différence entre les Steps et les spécialités

Dans le cadre des Steps, les éclais franchissent trois étapes pendant leurs années dans la branche Eclais. Ces trois étapes représentent une progression et en moyenne, un·e éclais peut passer une étape en une année. Pour obtenir l’insigne correspondant à l’étape, les éclais doivent prouver certaines connaissances et expériences définies par avance. Les exigences sont les mêmes pour tous les membres. Durant l’année scoute, les éclais ont la possibilité de s’approprier les connaissances nécessaires et de faire les expériences requises. C’est pourquoi il est recommandé de créer un lien entre chaque activité de la branche Eclais et les prérequis des étapes.

Dans le cadre des spécialités, les éclais choisissent eux-mêmes un sujet qui les inté- resse particulièrement dans une liste de spécialités. Donc, tous les éclais ne font pas la même spécialité. Pour chaque spécialité, des objectifs définissent ce que les éclais doivent atteindre pour obtenir l’insigne correspondant (comme pour les Steps). Contrairement aux Steps, une spécialité s’obtient après une préparation plus courte, typiquement la durée d’un camp d’été ou d’un trimestre. De cette manière, les éclais ont la possibilité d’approfondir leur connaissance du sujet et d’en devenir « expert·e » durant plusieurs activités.

Dans les deux cas, un certain temps est nécessaire pour préparer l’étape Steps ou la spé- cialité. C’est pourquoi il est recommandé de mettre en œuvre soit l’un, soit l’autre dans un camp. Évidemment, il est aussi possible d’organiser la conclusion d’une étape ou d’une spécialité dans le cadre d’un samedi après-midi.
