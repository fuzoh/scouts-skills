**4.1.2 Formulaire MiData « Créer un cours »**
Les champs présentés dans le tableau ci-après <u><mark>en couleur</mark></u> <u>sont obligatoires.</u>

|Titre|Champ|Entrée/remarque|
|---|---|---|
|Gé-<br>néral<br>|Nom|Le cours apparaîtra sous ce nom dans le tableau récapitulatif<br>des cours. Le nom peut être librement choisi, p.ex. cours de<br>base d'automne, cours de base sous tente, etc.|
|Gé-<br>néral<br>|Type de cours|Choisir le cours correspondant dans le menu déroulant.<br>Chaque cours correspond à une seule catégorie.<br>**Important :**Lorsqu’un cours préalable au cours de base est sé-<br>lectionné, des champs supplémentaires, nécessaires à l’admi-<br>nistration des camps, apparaissent automatiquement. Ils sont<br>expliqués dans la Sardine.|
|Gé-<br>néral<br>|Statut|Les significations des statuts sont expliquées**_au chapitre sui-_**<br>**_vant_**. <br>Attention, pour que les participant·e·s puissent s’inscrire, il est<br>important que le statut du cours soit « Inscriptions possibles ».|
|Gé-<br>néral<br>|No du cours|Voir**_chapitre précédent_**|
|Gé-<br>néral<br>|Personne de<br>contact|Les coordonnées de cette personne apparaissent sur le formu-<br>laire d'inscription. C’est à cette personne que les participant·e·s<br>doivent renvoyer le formulaire signé si nécessaire (de préfé-<br>rence la personne qui procédera à la répartition des partici-<br>pant·e·s au sein du cours).|
|Gé-<br>néral<br>|Lieu / Adresse|Lieu de déroulement du cours|
|Gé-<br>néral<br>|CAF|Uniquement pour les cours où un·e CàF est exigé.|
|Gé-<br>néral<br>|Langues de<br>cours|Sélection multiple également possible.|
|Gé-<br>néral<br>|Nombre de<br>jours OFAS|Le nombre de jours OFAS défini par l’Assistance Formation et<br>Encadrement lors de l’annonce de cours doit être inséré ici.|
|Gé-<br>néral<br>|Réalisé par|Possibilité de sélectionner des organisateurs de cours supplé-<br>mentaires si le cours est mis sur pied par plusieurs entités (p.ex.<br>regroupement de plusieurs AC) ou si le cours doit être aussi vi-<br>sible pour des personnes d’autres AC.|
|Dates|Désignation|Par exemple : jour de préparation, week-end de préparation,<br>cours principal…|
|Dates|Lieu|Lieu de déroulement du cours|
|Dates|Du / au|Apparaissent dans la vue d’ensemble du cours|
|Ins-<br>crip-<br>tion|Début et fin des<br>inscriptions|Peut être modifié ultérieurement, par exemple lors d'un prolon-<br>gement du délai d'inscription.|
|Ins-<br>crip-<br>tion|Conditions<br>d'inscription|Possibilité d'indiquer ici de plus amples informations concernant<br>les conditions d'admission, par exemple cours ou expérience<br>souhaités. Ces informations sont visibles par l’utilisateur·trice<br>lors de l'inscription.<br>Attention : les qualifications requises pour le cours correspon-<br>dant (selon les modèles de formation du MSdS et de J+S) appa-<br>raissent automatiquement (ne doivent donc pas être complé-<br>tées).<br>|

|Col1|Col2|Si un formulaire supplémentaire est nécessaire pour l'inscription<br>au cours, cela doit être mentionné ici et il est possible d’intégrer<br>un lien vers le document (par exemple, le document sur le site<br>internet cantonal ou dans un dossier Dropbox), ainsi le·la partici-<br>pant·e a directement le formulaire correct à disposition pour<br>s’annoncer.<br>Attention : les formulaires supplémentaires nécessaires pour un<br>certain type de cours (par exemple le formulaire papier pour les<br>participant·e·s de moins de 18 ans) apparaissent automatique-<br>ment et ne doivent pas être mis en lien.|
|---|---|---|
||Nombre maxi-<br>mal de partici-<br>pant·e·s||
||Inscriptions ex-<br>ternes|Si « oui » est sélectionné, un lien d'inscription pour partici-<br>pant·e·s externes apparaît sous l'information concernant le<br>cours. C'est le seul moyen pour que des personnes sans accès<br>MiData puissent participer au cours.|
||Recommanda-<br>tions néces-<br>saires|Choix multiple possible.|
||Préférence|Une alternative au cours choisi peut être indiquée à l’inscription<br>(est utile si le cours est complet et qu'il faut répartir dans un<br>autre cours).|
||Signature obli-<br>gatoire|Si « oui » est sélectionné, l'inscription apparaît sous forme de<br>formulaire que les participant·e·s doivent imprimer et signer.|
||Deuxième si-<br>gnature obliga-<br>toire|Si « oui » est sélectionné, l'inscription apparaît sous forme de<br>formulaire que les participant·e·s doivent imprimer, signer et<br>faire signer à une deuxième personne.|
||Désinscription<br>possible|Si cette option est activée, les participant·e·s peuvent se désins-<br>crire eux·elles-mêmes du cours dans la base de données.|
||Voir l’état des<br>inscriptions|Si cette option est activée, le nombre d’inscriptions actuel au<br>cours est visible pour tout le monde dans MiData.|
||Inscription pro-<br>visoire|Les inscriptions provisoires sont possibles uniquement entre<br>l'ouverture du cours (statut « confirmé ») et le début des inscrip-<br>tions (statut « inscriptions possibles »).<br>Cette fonction peut permettre à l'admin d'évaluer le nombre de<br>participant·e·s au cours.<br>Le nombre de participant·e·s provisoires (y compris les informa-<br>tions concernant le groupe) est indiqué dans le registre « ins-<br>criptions provisoires ».|
|Don-<br>nées<br>pour<br>l’ins-<br>crip-<br>tion*|Question « nu-<br>méro AVS »|Pour les cours J+S, choisir « Obligatoire », le numéro AVS étant<br>nécessaire à l’importation sur la BDNS.<br>Pour les cours non-J+S, choisir « Non affiché ».|
|Don-<br>nées<br>pour<br>l’ins-<br>crip-<br>tion*|Question|Par exemple sur l’abonnement de train|
|Don-<br>nées<br>pour<br>l’ins-<br>crip-<br>tion*|Réponses pos-<br>sibles|Séparer les réponses possibles par des virgules<br>Par exemple : AG, demi-tarif, Voie 7, aucun|
|Don-<br>nées<br>pour<br>l’ins-<br>crip-<br>tion*|Sélection mul-<br>tiple|Si cette case est cochée, il sera possible de sélectionner plu-<br>sieurs réponses lors de l’inscription.|
