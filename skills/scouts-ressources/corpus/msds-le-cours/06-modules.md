Une fois les contenus listés, il convient de les rassembler pour former les modules. Un module
regroupe plusieurs unités d’apprentissage, afin d’aborder de manière structurée et progressive
des sujets similaires. Les modules servent de cadre pour organiser les contenus détaillés et
structurer le programme de formation de manière claire et efficace.

Cette étape intermédiaire de formation des modules présente plusieurs avantages, tant pour
l’équipe de cours que pour les apprenant·e·s. D’une part, elle offre une meilleure vue d’ensemble des contenus, facilitant ainsi la construction d’une progression pédagogique cohérente
sur une même thématique. D’autre part, la visibilité des modules dans le programme aide les
apprenant·e·s à mieux appréhender la logique globale du cours.

La première étape consiste à rassembler les contenus de formation en de larges ensembles,
d’après leur proximité thématique. Les contenus peuvent être issus d’objectifs de formation différents. Des contenus similaires peuvent se retrouver à plusieurs reprises dans le même ensemble ; le regroupement en unités d’apprentissage permettra de donner du sens à cette redondance. Chaque module reçoit ensuite un titre.

Le nombre de modules idéal n’est pas strictement défini et varie selon le type de cours. À titre
indicatif, un cours de base contient généralement entre cinq et sept modules. Un trop petit
nombre indique que les contenus ont été regroupés de manière trop large. Or, si un module
