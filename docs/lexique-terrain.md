# Lexique du terrain

Termes rencontrés dans un échantillon de dossiers réels de camps et de cours (non publiés), absents du vocabulaire officiel ou employés autrement. `[non officiel]` : sert à interpréter une demande (« mon picasso », « la HM a dit… ») ; jamais à normer. Confiance : sûr / probable / hypothèse. Les termes déjà dans `GLOSSARY.md` ne sont repris que si l'usage terrain diffère.
