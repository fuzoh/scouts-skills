## ⛰️ 3x3 – activités itinérantes

|  | Conditions | Terrain/Environnement | Facteur humain |
|---|---|---|---|
| **Planification**: Quelle sera la situation? | A quelles conditions doit-on s’attendre pendant l’activité en fonction de la saison, du moment de la journée? | Quelles difficultés comporte le terrain? Comment l’activité doit-elle être adaptée à l’environnement? | Quelle est la composition prévue du groupe? (par ex âge, taille, besoins d'encadrement, condition, expériences) Comment le groupe doit-il être structuré et dirigé? (Composition et expériences de la maitrise)? |
| 👉 Quels sont les dangers? 👉 Quelles mesures faut-il prendre contre ces dangers? |  |  |  |
|  **Sur place:** Les hypothèses avancées lors de la planification sont-elles confirmées? | Quelles sont véritablement les conditions sur place et quelles sont les prévisions pour la suite de la journée? | L’activité se déroule-t-elle à l’endroit prévu, sur l’itinéraire prévu? | Quelle est la véritable composition du groupe? Forme du jour, condition, motivation? Dynamique de groupe? Equipement prévu disponible? |
| 👉 En résulte-t-il de nouveaux dangers? Les mesures doivent-elles être adaptées ou complétées? |  |  |  |
| **Pendant l’activité:** Comment les conditions évoluent-elles pendant l’activité? | Comment évoluent les conditions pendant l'activité (vent, pluie, température, nuages, vue)? | Le terrain correspond-il à ce que j’imaginais? | Comment l’état physique/ psychique du groupe/des participants évolue-t-il? |
| 👉 En résulte-t-il de nouveaux dangers? Les mesures doivent-elles être adaptées ou complétées? |  |  |  |
