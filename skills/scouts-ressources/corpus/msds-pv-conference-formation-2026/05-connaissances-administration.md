Celia Roduner / Aurea 12.09.2026

Les connaissances techniques de base s'orientent sur les formes caractéristiques et comprennent des contenus dans les domaines de techniques de cordes et constructions, des premiers
secours ainsi que de la lecture de carte et de l'orientation.

Dans le modèle de formation, qui entre en vigueur le 1er janvier 2027, cela est formulé ainsi :

  - Nouveau cours : Connaissances techniques de base SdC/T

  - Condition d'admission au cours de base : « Connaissances techniques de base SdC/T
(peuvent aussi être développées durant le cours) »

Dans le cadre de référence du cours de moniteur·rice·s J+S SdC/T, cela est formulé ainsi :

  - Conditions d'admission spécifiques : « Connaissances de base du document ‘Connaissances techniques de base SdC/T’ »

  - Objectif du cours : « Les participant·e·s sont capables d'encadrer les connaissances
techniques de base prescrites en SdC/T. »

**Administration des cours**
**Diapositives 29-30**
Des changements ont également lieu dans MiData avec le nouveau modèle de formation ; Aurea résume les principaux changements :

Cours de base

  - Un nouveau type de cours « cours de base » est créé.

  - Les types de cours « cours de base Louveteaux » et « cours de base Éclais » seront
archivés fin 2027.

  - Les cours pour 2027 peuvent déjà être saisis (si nécessaire encore avec les anciens
types de cours) – dans ce cas, le type de cours devra être adapté dès que le nouveau
type de cours existera.

  - Dès 2027, une seule qualification « moniteur·rice J+S SdC/T » sera attribuée, et non
plus deux reconnaissances spécifiques aux groupes cibles. Toutes les reconnaissances
existantes seront transférées vers la nouvelle.

Cours de responsable d’unité

  - Il n'existera désormais plus qu'un seul type de cours « cours de responsable d’unité ».

  - Rien ne change au niveau de la qualification.

  - Pour l'administration, il en va de même – les cours peuvent déjà être saisis, pour l'instant encore dans les anciens types de cours.

Modules de formation continue J+S

  - Afin de pouvoir vérifier directement si une personne a terminé le niveau « formation
continue Foundation », une nouvelle qualification « module de formation continue J+S
accompli » est introduite pour les modules de formation continue J+S. Cela est nécessaire pour la vérification des conditions d'admission au cours Top.
