# Check-list pour un programme équilibré

1\) Planifier des activités/un programme trimestriel/un programme annuel.

2\) Quelles sont les relations présentes dans ces activités ?

3\) Est-ce que toutes les relations sont présentes de manière égale dans le programme ?

4\) Quelles méthodes sont présentes dans ces activités ?

5\) Est-ce que toutes les méthodes sont présentes de manière égale dans le programme ?

<u>POSSIBILITÉ 1</u>

toutes les relations et les méthodes sont présentes

6\) Super, ne rien changer !

<u>POSSIBILITÉ 2:</u>

une ou plusieurs relation(s) et méthode(s) sont peu ou ne sont pas présente(s)

6\) Lorsque c’est possible, ajouter les relations et méthodes manquantes au programme actuel ou les inclure dans le programme suivant.
