#### **3.2 Pousser le VTT**

Tous les passages ne peuvent pas être empruntés à vélo. Selon la situation, il est plus rapide, ou
plus sûr, de pousser le VTT. Le vététiste doit donc aussi savoir le pousser. Toutes les variantes – p. ex.
marcher avec le vélo entre les jambes – sont à proscrire dans la mesure où le risque de chute est
extrêmement élevé.
