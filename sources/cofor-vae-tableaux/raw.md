# introduction
| Valoriser les acquis du scoutisme dans le monde du travail |
| --- |
|  |
| Aux scouts, on s’investit beaucoup, bénévolement, pour permettre à ce mouvement auquel nous sommes attaché.e.s de vivre. A priori notre motivation première n’est pas de rentabiliser cet engagement. Cependant l’engagement bénévole –scout ou non- permet d’acquérir des compétences, parfois imprévues, qu’il est possible de mettre en avant lorsque l’on cherche un travail. Alors certes, cela ne remplace pas un diplôme ou une expérience professionnelle de plusieurs années, mais savoir comment utiliser ses expériences scoutes face à un recruteur peut faire la différence. C’est la raison d’être des tableaux des pages suivantes. |
| NaN |
| Quand et comment utiliser ces tableaux ? |
|  |
| Il peut y avoir plusieurs situations : |
| NaN |
| Tu te demandes ce que les scouts t’ont apporté, en quoi tu es compétent.e et ce que tu aimes faire pour identifier ce que tu pourrais aimer faire hors des scouts, quelle formation effectuer, à quel job postuler, etc. |
| Alors, tu remplis les colonnes 2 à 4 et tu regardes ensuite quels sont les champs de compétences dans lesquels tu as le plus de points et si tu as de la chance cela correspondra avec les compétences demandées par un métier existant tel que décrit dans une offre d’emploi ou sur www.orientation.ch  Prévois d'avoir plusieurs heures à y consacrer. |
|  |
| Tu veux préparer un entretien d’embauche, ou une lettre de motivation |
| Alors, tu regardes les compétences demandées par le poste et utilises les colonnes 1 à 4 des expériences correspondantes. Durant l’entretien, il est attendu que tu partes de la compétence pour ensuite arriver à l’expérience concrète (avec une date, une fonction, etc.) |
| A ce moment, il faut aussi trier pour trouver un bon exemple réussi plutôt que 12 expériences mitigées. De même, une habitude a plus de valeur que quelque chose que vous n’avez fait qu’une seule fois. Il est aussi important d’oser identifier ses incompétences ; Et de plutôt mettre en avant ses compétences, naturellement ;) La feuille intitulée "résumé" permet ensuite de faire le tri pour ne garder que ce qui permettra vraiment de faire la différence. |
|  |
| Important ! Cette liste n’est pas fermée elle n’est qu’un outil qui montre une méthode. On peut tout à fait attester de sa capacité à prendre en compte les besoins d’un client en disant que l’on adapte menus aux régimes alimentaires des participants (et attester par-là que l’on sait faire preuve de créativité^^) De même, il n’est pas besoin d’inventer des expériences et des compétences que l’on n’a pas développées, donc c’est parfaitement normal si toutes les cases ne sont pas remplies. |
|  |
| Bonus : certaines compétences sont validées de manière formelle ; si tel est le cas n’hésite pas à utiliser les attestations des cours de formation. |
| NaN |
| Pourquoi y a-t-il deux tableaux? |
| Les compétences transversales sont les mêmes, mais les fonctions donnent lieu à des types d'expériences différentes. C'est la raison pour laquelle nous avons créé deux tableaux; l'un correspondant aux expériences des responsables d'unité et responsables d'unité adjoint.e.s, l'autre à celles des responsables avec des fonctions d'encadrement, de formation ou au niveau de leur association cantonale ou régionale. Il va de soit qu'il est possible d'utiliser une expérience de RU même si on est RG. |
| NaN |
| références: |
